# Design System Specification

## Brand
Create an original marketplace brand. Do not use Amazon's logo or exact brand identity.

## Layout
- Desktop content max width: approximately 1280–1440px.
- Main page background: light neutral.
- Cards: white or slightly elevated surfaces.
- Use consistent 4px-based spacing.
- Use a 12-column desktop grid where useful.
- Mobile uses one-column layouts with horizontal scrolling only for intentional carousels.

## Header
Use a layered header:
1. Utility/top strip
2. Main header with brand, delivery/location, search, account, orders, cart
3. Category/navigation strip
4. Optional page-specific sub-navigation

## Visual tokens
Define tokens for:
- background
- surface
- border
- text
- muted text
- primary action
- secondary action
- danger
- success
- warning
- focus ring

## Responsive behavior
Desktop:
- full header navigation
- multi-column product grids
- sidebar filters
- two-column product detail
- checkout summary column

Mobile:
- compact header
- search below main controls if needed
- collapsible menu drawer
- filter/sort drawer
- one-column product details
- sticky action bar only when it does not hide content
- touch targets around 44px or larger

## Typography
Use one primary sans-serif font. Establish a clear hierarchy:
- page title
- section heading
- product title
- price
- body
- helper/caption
- badge/label

Do not make every element extra bold. Use weight and spacing consistently.
