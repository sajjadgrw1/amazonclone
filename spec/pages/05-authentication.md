# Login and Signup Specification

## Visual structure
- centered auth card
- brand mark
- email/phone input
- password input
- show/hide password
- primary submit
- alternate links
- terms/helper text

## Functional behavior
- client-side validation
- submit loading state
- invalid credentials error state
- login success routes to intended destination
- signup validates password confirmation
- signed-in header changes account menu

## Security
- prototype only: use mock authentication
- never collect or persist real passwords
- clearly label mock behavior until a secure backend exists
