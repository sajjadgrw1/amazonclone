# Orders Specification

## Visual structure
- page title and status tabs
- date/order number filters
- order cards
- product thumbnails
- total and status
- action buttons
- empty state

## Functional behavior
- filter by status
- open order details
- mock track order
- cancel/return actions show confirmation modal
- search orders by order number or product

## Implementation
- use typed Order and OrderItem models
- show status badges with accessible text
- provide mobile stacked order cards
