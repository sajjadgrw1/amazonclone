# Lightning Deals Specification

## Visual structure
- active/upcoming tabs
- horizontal category shortcuts
- deal cards with timer and discount
- claimed progress bar
- waitlist or sold-out state
- deal detail link

## Functional behavior
- timer updates from end timestamp
- expired deals become disabled
- add to cart validates availability
- upcoming deals show start time
- waitlist is a mock action

## UX note
Use a clear visual distinction between active, upcoming, expired, and sold-out deals.
