# Sell / Seller Portal Specification

## Routes
- /sell
- /sell/how-it-works
- /sell/pricing
- /sell/register

## Sell landing
- seller value proposition
- steps to start selling
- categories
- fees/pricing CTA
- seller FAQ
- registration CTA

## Registration
- business/person details
- contact information
- store name
- category selection
- validation
- progress steps
- success/pending review state

## Pricing
- fee explanation cards
- calculator using mock rates
- clear disclaimer that values are demo data

## Implementation
- keep buyer and seller navigation separate
- use reusable form fields and stepper
- do not request real identity or banking information in prototype mode
