# Footer Specification

## Visual structure
- back-to-top button
- grouped navigation columns
- customer service
- sell/business links
- payment/gift card links
- account/help links
- language/country selector
- legal links
- copyright line

## Functional behavior
- back to top scrolls to page top
- all links route to real mock pages or show a clear not-connected state
- mobile groups collapse into accordions
- language/country selector opens modal
